## 1. 学生先读：这是一份"参照—对应"手册

**组织思路：参照驱动（precedent-driven）。** 生物医药、基因组学、医疗 NLP 等领域已经产出一批经顶刊/顶会验证的大模型安全研究。本文档把它们当作**引子、例子和参照对象**，并为每条参照补齐三样东西：它验证的范式**成立的前提**、材料侧对应的**具体问题**、可直接上手的**材料模型与数据**。**迁移本身是要检验的假设**：满足前提的直接迁移范式；不满足的，"这个范式为什么在材料上行不通"本身就是可发表的研究问题。

**学生三步用法：** ① 在 §2 对应总表里按行找到"参照 → 材料问题 → 模型数据 → 章节"的完整链路；② 跳到"详见"章节读威胁模型与最小实验；③ 回 §8 配对模型与数据、按 §9 协议开跑。

核心问题：攻击者能否在整体误差变化很小的情况下，操纵某一材料族的预测、候选排序或计算决策；我们能否发现、定位并阻断这种操纵？

建议至少安排一位学生独立开展第7节 **Generated Material Safety**，从生成结果的证据与不确定性评估过渡到AI4Materials；它不要求存在攻击者。

攻击与检测主线推荐第一题：**材料基础模型微调阶段的定向数据投毒与检测**。先在可控数据划分上研究带隙或能量任务，再扩展到结构后门。只有 CPU 的学生可从供应链完整性审计或小规模 RAG 检测开始。具备计算材料合作和 DFT 资源后，再做物理约束对抗攻击和非线性光学材料验证。

这里的基础模型不等于聊天模型，也不以参数量达到十亿为门槛：

| 对象 | 输入与输出 | 本文中的作用 |
|---|---|---|
| 通用机器学习原子间势（MLIP） | 元素、周期晶格、坐标 → 能量、力、应力 | CHGNet、MACE、DPA-2；重点研究数值预测与下游弛豫 |
| 分子表示基础模型 | 分子图、三维构象 → 表示或下游性质 | Uni-Mol2；适合分子材料，不直接等同于无机周期晶体模型 |
| 化学多模态语言模型 | 文本、分子或光谱等 → 回答与推理 | ChemDFM-X；适合知识和跨模态实验，不能默认支持任意 CIF 晶体 |
| 材料 RAG / Agent | 检索结果、数据库条目、工具返回 → 回答或操作 | 系统安全对象；可由通用 LLM 加材料知识库构成 |
| 传统材料 ML | 组成特征、晶体图 → 性质 | 随机森林、CGCNN 等用于对照；单独攻击它们不足以支撑“基础模型安全”结论 |

**需要先学的材料概念：** CIF、周期边界、原胞与超胞、配位环境、结构弛豫、形成能与凸包距离、能量/力/应力的单位、DFT 计算设置。代码接口能运行，不代表科学评价成立。

### 三条使用原则

1. **参照论文是引子，不是证据。** 原领域的攻击成功率、污染比例、权重修改量不能外推为材料结论；材料实验按 §9 协议重新报告。
2. **先对照前提，再谈迁移。** 满足表A"前提"栏的直接做范式迁移；不满足的写成"范式改造"——贡献是让它在材料条件下重新成立（或证明不能成立）。
3. **行不通本身是研究问题。** 材料的独有特性——周期等价、连续回归输出、DFT 真值昂贵、组内相关性——很可能使跨领域范式失效；失效机制与失效条件的形式化，是本方向区别于"换数据集刷通用攻击"的核心贡献点。

**层次交叉说明：** 前四层（Data/Model/Privacy/System）按主要攻击入口组织，存在交叉——结构后门通常在数据层植入、在模型层保留；权重篡改可通过供应链分发；RAG 污染发生在推理知识库，不能据此声称预训练被投毒。

## 3. Data Security

### D1. 定向训练数据投毒与检测｜参照：[R1] 医疗 LLM 投毒、[R2] 基因组投毒（表A）

**参照对应（→ §2 表A/B）。** [R1] 研究医疗错误知识混入语言模型训练数据；[R2] 包含基因模型预训练投毒和下游标签污染。可迁移的是“局部目标损害可能被整体指标掩盖”的威胁模型，而不是 token 污染比例或医疗攻击成功率。材料应分别报告污染结构数、标签数、轨迹数与实际训练曝光次数。

**研究问题。** 攻击者仅能污染一部分微调数据，能否使指定化学体系被错误筛入候选集合，同时逃过常规 MAE 与异常值检查？

**模型与数据。** 入门用 CHGNet 或小型 MACE 的预训练表示加性质头，配 Matbench 的结构型带隙任务；同时保留从头训练的材料 GNN 和组成特征模型。原生势函数实验用 MPtrj 的可控微调子集。带隙、SHG 不是这些势函数默认输出，必须训练任务头。NLO 扩展可选 SHG-25。

**最小实验。**

1. 按母体结构/轨迹分组，先冻结训练、验证、目标测试及非目标测试划分。目标元素族必须在实验前选定。
2. 只改变训练部分，比较干净训练、随机标签噪声、家族定向偏移及有干净性能约束的定向投毒。
3. 建议探索 0、0.1%、0.5%、1%、5% 的结构污染比例；样本不足时直接报告整数个数，不向上包装精度。另报目标族内部污染比例。
4. 测整体与分族 MAE、目标偏移方向、Top-K precision/recall、好材料漏选率及坏材料误选率。固定候选池和 K。
5. 对照来源校验、标签残差检测、稳健训练；再研究“来源—结构邻域—物理标签”联合检测，报固定误报率下的召回和过滤后的效用。

**创新候选。** 低总体误差下的发现排序操纵；利用相近结构的物性一致性识别定向污染；污染跨预训练表示和微调任务的迁移。这些均是待验证假设，仅换一个数据集不是充分创新。

**关键控制。** 标签偏移是否只是换单位、不同泛函或能量参考造成？若同时训练 E/F，应说明污染是否保持 F = −∇E；把能量改了而不检查力，可能只制造了容易识别的错误数据。形成能筛选须使用统一元素参考，不能把原始总能量直接当作凸包距离。

**设备与优先级。** P1。CPU 可做特征基线；单张 16–24 GB GPU、32–64 GB 内存适合小结构和小批量试验。先运行 100 个结构估计显存和每轮耗时；不需要合成、XRD 或显微设备。

### D2. 结构后门与检测｜参照：[R2] DNA motif 后门、[R3] Graph Backdoor（表A/B）

**参照对应（→ §2 表A/B）。** [R2] 的 DNA motif 提供条件触发思想；[R3] 的子图触发提供图结构方法。晶体图来自几何邻域，不能直接插入任意边；DNA motif 也不能原样变成晶体 motif。

**研究问题。** 在原子排列、晶格表达变化后仍一致的局部触发，能否使模型产生错误的目标预测，并在常规微调后保留？

**模型与数据。** CHGNet / MACE 的可控微调模型；MPtrj 中选一种或少数明确化学体系。先用小型材料 GNN检验流程，再扩展基础模型。缺陷或替位结构需要新增参考标签。

**最小实验。**

1. 先定义一个材料上可解释的局部配位或受限位移触发；元素替位、空位和间隙作为后续更困难的变体。
2. 比较四组：干净模型+原结构、干净模型+触发结构、污染模型+原结构、污染模型+触发结构。新结构均按同一参考方法取真值。
3. 在相同预算下比较固定与适配式触发、随机合法扰动、标签投毒无触发，以及同成分/缺陷浓度但不同局部几何的对照。
4. 测触发后定向错误率、无触发误触发率、正常性能、旋转/平移/原子重排与等价晶胞下的一致性，以及经过弛豫和干净微调后是否保留。
5. 检测基线：表示异常、局部结构频率与激活聚类；候选方法是物理匹配反事实检测。训练、检测阈值与最终攻击测试分开。

**创新候选。** 对等价表示稳定、对物理无效结构不依赖的触发；弛豫过程中的触发消失与再激活；跨材料族迁移和结构级定位。

**关键控制。** 缺陷和掺杂本来就会改变真实物性；模型输出变了不等于后门成功。必须看到相对于新结构真值的定向错误，并证明超出干净模型的正常响应。旋转后的力和 SHG 张量要同步变换。没有新结构真值时，只能报告模型响应异常。

**设备与优先级。** P1，建议 D1 完成后启动。单张 24 GB GPU可尝试小模型；物理有效性验证另需 CPU/DFT 配额和材料合作者。DFT 资源未落实时先做可复用原有标签的等价表示测试，但它不等同于完整结构后门研究。

## 4. Model Security

### M1. 权重篡改与模型完整性检测｜参照：[R4] 医疗权重编辑、[R5] Bit-Flip（表A/B）

**参照对应（→ §2 表A/B）。** [R4] 通过定向修改医疗 LLM 的部分权重植入错误事实；[R5] 研究权重比特翻转。前者是参数编辑，后者是受存储表示约束的攻击，必须作为不同实验，不把任意浮点编辑称为硬件攻击。

**研究问题。** 第三方模型或适配器只改变少量参数，能否使特定材料族出现能量偏差或错误排序，而正常验证集通过？

**模型与数据。** CHGNet、小型 MACE；MPtrj 微调子集及独立材料族。语言侧可在支持的 ChemDFM-X 任务上研究错误化学事实，但与势函数实验分别报告。

**最小实验。** 声明攻击者可写检查点、适配器或特定位存储；比较随机同范数扰动、受约束目标编辑、无约束编辑上界。逐档限制参数数量、改变量范数和干净损失，测目标误差、排序、有限步弛豫轨迹与正常性能。防御比较可信原版哈希、合法更新清单、分族行为探针，以及能量/力/应力的一致性探针。合法微调作为重要阴性对照。

**创新候选。** 在没有逐字节相同“原模型”的合法微调场景下，定位定向恶意更新；把参数变化和物理响应变化联合解释。不要仅提出校验和并称为新方法。

**关键控制。** 有可信原版时哈希可发现任何字节改变，但无法判断改变是否恶意；来源本身不可信时哈希也无助。对通过能量求导构造力的模型，F = −∇E 在错误权重下仍可成立，因此一致性检查不是充分防御。数值模拟不构成 Rowhammer 实物验证。

**设备与优先级。** P2。小模型单张 16–24 GB GPU；哈希和格式检查用 CPU。硬件故障注入是另一个课题，不作为起步前提。

### M2. 物理约束对抗攻击与稳健性检测｜参照：[R6] Madry 框架；材料侧已有 [R7][R8]（表B/C）

**参照对应（→ §2 表A/B）。** [R6] 提供约束优化和鲁棒评价框架；[R7–R8] 已经把对抗结构用于原子势主动学习。不能声称“首次将对抗样本用于材料”。可研究安全权限、隐蔽性、定向决策与检测规避，这些与提高训练采样效率不同。

**研究问题。** 攻击者只能改提交的几何结构，且受物理可行性和预算约束，能否误导筛选或弛豫决策？

**模型与数据。** CHGNet、MACE，后续 DPA-2；MPtrj/Matbench Discovery 的受控结构子集。[R7] 的公开数据和实现可作为方法复现入口。

**最小实验。**

1. 分别研究坐标位移、晶格应变；原子种类/数目、最小原子间距、体积、周期性、组成等约束逐项列明。是否保持空间群取决于任务，不能一概要求。
2. 随机合法扰动与投影优化使用相同预算；区分白盒梯度、替代模型迁移与黑盒查询设置。
3. 对扰动后结构取得参考能量/力。评估相对参考值的误差增幅、约束满足率、定向排序错误率与参考计算成本。
4. 分开测试输入尚未弛豫和弛豫后的结构；若声称动力学风险，要评估轨迹层指标，不能只用单点 MAE 推断。
5. 对比结构检查、不确定性拒绝、对抗训练；用面向防御的自适应攻击检验是否只是梯度遮蔽。保留未用于调参的材料族。

**创新候选。** 受明确几何与能量预算约束的定向候选误筛；高置信错误与不确定性失灵；误差在弛豫中的积累及可提前检测信号。

**关键控制。** 改坐标会改变真实能量，不能固定原标签。势函数之间互相对照只给出代理分歧，不能替代 DFT 真值。等价旋转不应改变标量性质，但力要旋转；只测试此类等价变换属于一致性审计。DFT 验证也不等同于可合成性证明。

**设备与优先级。** 有计算材料支持时 P2，否则 P3。单张 24 GB GPU用于攻击搜索；参考计算通常需要多核 CPU/集群，其成本依原子数、泛函、k 点和收敛要求测定。先选约 20 个小结构做参考计算可行性试验，不承诺固定 GPU 小时或无需材料知识。

## 5. Privacy & IP Security

### P1. 材料模型窃取与查询异常检测｜参照：[R9] 预测 API 窃取（表B）

**参照对应（→ §2 表A/B）。** [R9] 建立通过预测 API 复制功能的研究框架。材料中应关注私有微调能力、专有适配器或隐藏服务；公开且可下载的原版权重本身不是有说服力的窃取目标。

**研究问题。** 相同查询成本下，能量、力、应力和表示的不同返回策略，会泄露多少可复制能力？

**模型与数据。** 将自己的 CHGNet/MACE 私有微调副本封装为本地 API；公开结构池作为查询候选，另留不重合的审计测试集；分子表示扩展可用 Uni-Mol2。受害者私有标签不提供给攻击者。

**最小实验。** 比较随机、结构多样性和主动学习查询；建议先做 1k/5k/10k 个结构预算。分别测试仅能量、能量+力、表示返回。替代模型对照同等公开数据训练但不访问 API 的版本。测受害者—替代模型 fidelity MAE、对真实标签的 utility MAE、Top-K 重合率、跨材料族泛化及查询数；记录每次返回的标量数，因为一个含 N 个原子的力响应包含 3N 个数值。

**检测与创新候选。** 识别提取型查询的覆盖/自适应特征，评估精度限制和速率限制的效用代价；研究物理导数输出的单位查询信息收益。用正常高通量筛选和主动学习日志作为阴性对照，避免把科研用户都识别为攻击者。

**设备与优先级。** P2，单张 16–24 GB GPU通常可启动小模型实验；CPU承担 API 和日志。无需访问或付费轰击第三方 API；结论限定于公开声明的本地威胁模型。

### P2. 成员推断与结构重构：两个不同问题｜参照：[R10] LiRA、[R11] 基因嵌入重构（表A/B）

**参照对应（→ §2 表A/B）。** [R10] 强调低误报率下的成员推断评价；[R11] 研究基因模型嵌入的序列重构。嵌入泄露的是输入信息，不自动证明训练数据记忆；晶体坐标还有平移、旋转、原子置换与周期等价性。

**问题 A：成员推断。** 某结构是否参与了私有微调？已知标签的损失攻击与未知标签攻击应分别定义。

- **模型/数据：** CHGNet/MACE 的自有微调模型和明确的成员名单；Matbench 或 MPtrj 分组子集。公开基础模型预训练成员未知时，不能声称验证了预训练成员泄露。
- **实验：** 损失阈值、参考模型校准、LiRA 思路的影子模型对照。先固定同分布成员/非成员，再单独研究分布偏移；禁止用训练集和完全不同材料族的测试集制造虚高效果。
- **指标/防御：** ROC-AUC 和 TPR@1% FPR，负样本足够时再报 TPR@0.1% FPR；附置信区间与样本数。比较正则化、早停、降低输出精度；若研究 DP，明确以结构还是轨迹为邻接单位并记录隐私预算。
- **创新候选：** 轨迹相关性造成的虚假成员推断；家族级私有研发范围泄露；物理等价表示下的攻击稳定性。

**问题 B：结构重构。** 攻击者已知组成/原子数吗？拿到的是逐原子表示、池化表示，还是少量性质值？这些决定可识别性。

- **模型/数据：** 小型晶体编码器/CHGNet 表示接口；分子试验用 Uni-Mol2。攻击者只在辅助集合上训练重构器，测试私有集合必须隔离。
- **实验：** 对比逐原子与池化嵌入、不同维数、量化与噪声；以已知组成的有限候选检索作为简单基线，再考虑坐标重构。成员与非成员输入都测，区分输入可逆性与训练记忆。
- **指标/防御：** 经周期等价匹配后的结构恢复率、晶格误差、原子匹配后 RMSD、局部配位恢复率；报告候选多解和失败率。比较表示压缩/噪声后下游性质性能。
- **创新候选：** 在同等预测效用下研究表示泄漏边界；区分完整结构、配方、局部 motif 三种泄漏；揭示等价结构造成的虚假重构失败。

**关键控制。** 仅公开成分即可猜出的结构不是模型泄密证据；从单一带隙值恢复唯一晶体一般缺乏可识别性。用公开数据模拟私有集合不代表已证明真实商业秘密泄露。

**设备与优先级。** 成员推断 P2；重构 P3。单张 24 GB GPU可串行训练小影子模型，先做 4–8 个调试再决定是否扩大；完整 LiRA 的稳定估计可能需要更多模型。不能把小试验叫作完整复现。重构试验可能需要 24–48 GB GPU，先从小结构和检索基线做起。

<a id="system-security"></a>

## 6. System Security

### S1. 材料 RAG / Agent 投毒与证据验证｜参照：[R12] CorruptRAG、[R13] AgentDojo（表B）

**参照对应（→ §2 表A/B）。** [R12] 研究少量知识库文档污染；[R13] 将工具任务效用和攻击成功分开评测。材料文档的事实篡改和“忽略要求”等指令注入是不同攻击，须分开标注。

**研究问题。** 一条受污染的物性记录或工具返回，能否让 Agent 错选候选、改错单位或跳过必要验证？证据追溯与物理约束能否发现它？

**模型与数据。** 先用一个可复现的小型开源指令模型+本地材料 RAG；第二个骨干做迁移验证。ChemDFM-X仅用于它支持的模态/任务对照。语料选可合法复用的材料数据库记录、开放论文及官方说明，建立自己的正确答案和引用证据；这不是已存在的材料安全基准。

**最小实验。**

1. 先建立约 100–200 个可核对任务，涵盖属性查找、单位换算、证据选择与候选排序。任务按材料实体/论文来源划分，防止问法重复泄漏。
2. 分别污染检索库文档、属性表、工具说明和工具返回；仅在本地副本操作。使用匹配的良性文档变体控制长度和检索影响。
3. 记录污染文档检索命中率、命中后条件成功率和全部任务端到端成功率；未检索到不能偷偷从分母删掉。
4. Agent 使用仿真工具，如读取性质、计算排序、提交模拟验证任务；错误动作由规则判定。不能仅凭最终回答断言工具已执行。
5. 比较来源白名单、证据交叉校验、单位/数值校验、可信控制流与工具权限策略；再用自适应污染测试绕过。报告正常任务完成率、误拒绝、延迟与 token 成本。

**创新候选。** 从“来源—结构身份—计算条件—属性单位—决策动作”检查证据链；发现多个独立来源其实是同一条错误数据的转载；定位错误如何传入下一步计算。

**关键控制。** 多个 LLM 认同不是物性真值。训练和测试中的虚构恶意条目必须有清晰标记，不能混入真实公共数据库。合成路线只做离线证据与策略判定，不据此声称实验成功或实际设备受控。

**设备与优先级。** P1，最适合有 NLP/Agent 经验的学生。CPU可建索引，16–24 GB GPU可尝试小模型量化推理；较大多模态模型可能需要 48–80 GB或多卡，按官方具体版本另测。API方案可省本地 GPU，但须单独预算费用并固定版本。

### S2. 材料模型供应链完整性与恶意行为检测｜参照：[R14] EvilModel、[R15] 工程基线（表B）

**参照对应（→ §2 表A/B）。** [R14] 说明模型参数可携带隐藏载荷；[R15] 说明不可信模型加载具有代码执行风险。这与统计后门不同：格式安全不保证预测可信，载荷藏在权重里也不意味着普通推理会自动执行它。

**研究问题。** 仅看检查点或依赖 CVE 是否足以判断风险？能否联合分析模型、配置、数据处理与运行行为，发现会改变材料计算含义的篡改？

**对象与数据。** CHGNet、MACE、DPA-2、Uni-Mol2 等官方仓库和发布制品的版本化元数据；记录 commit、权重哈希、来源、许可证和依赖。公开项目只是研究对象，**不应因其使用某格式就标记为恶意**。

**最小实验。**

1. 建立有快照日期的小型样本集。干净官方制品、合法微调/重打包、已标注的人工篡改变体分别保存来源。
2. 用无害标记构造加载行为试件，在无凭证、受限网络的隔离环境观察文件和进程行为；不运行真实恶意载荷。
3. 除权重变化外，测试元素类型映射、归一化、能量单位和配置被更改，但权重文件未改变的情形。
4. 比较哈希/签名、格式静态检查、依赖审计、动态行为与物理探针组合；评估 precision、recall、固定 FPR 检出率、定位正确性、覆盖率和扫描开销。
5. 对合法量化、正常导入行为、模型格式迁移进行误报控制；以受控变体证明检测能力，外部生态扫描只能报告核实程度与覆盖范围。

**创新候选。** 检查点、配置和物理语义的一致性验证；能定位到污染环节的模型更新证据链；区分代码执行风险、数据完整性问题与统计后门。

**关键控制。** CVE 数量不是成功攻击数量，人工构造样本不能当作真实野外恶意样本。可信签名证明发布来源而非科学正确性；safetensors 降低反序列化代码风险，却不消除恶意权重、外部依赖或配置风险。

**设备与优先级。** P1。32 GB 内存的 CPU 工作站即可启动静态/动态检测；24 GB GPU仅在需要大批行为预测时增加。无需材料合成设备。

<a id="generated-material-safety"></a>

## 7. Generated Material Safety：生成材料安全与可信生成｜参照：[G9] 药物 dual-use、[G8] 通用对齐（表A/C）

这是独立的第五方向：即使没有攻击者，模型也可能生成不可实现、风险较高或证据不足的材料。它与投毒/后门的区别在于研究对象是**生成结果及其使用情境的风险**，并不要求存在恶意修改。也可以另设攻击者操纵安全评价器的交叉课题，但不能将其作为本方向的定义。

**推荐至少一位学生专门开展：Generated Material Safety Evaluation with Evidence and Uncertainty。** 第一阶段复用现有生成样本，建立能解释风险并识别证据不足的评估流程；第二阶段再做安全约束生成。不要一开始同时训练生成器、毒性模型、合成模型和生命周期模型。

### 7.1 依据、已有工作与真正的研究边界

MatterGen [G1] 提供性质条件生成和实验验证案例；LeMat-GenBench [G2] 统一评价有效性、分布、多样性、新颖性和稳定性，官方实现**已经包含 HHI 供应集中度指标**。因此不能把“给生成材料加供应风险”本身写成首次。晶体生成综述 [G3] 和材料基础模型综述 [G4] 为可合成性与化学正确性讨论提供背景。

更贴近安全评估的方法参照是 SSbD [G5]、CHIASMA [G6] 和纳米颗粒毒性预测 [G7]。跨领域可对应通用 LLM 的有用性—无害性权衡 [G8]，以及生物医药生成模型的双重用途风险研究 [G9]；迁移的是评价目标、约束和不确定性意识，不是直接把文本奖励模型当成材料安全判据。

**文献纠正：** CHIASMA 文献发表于 *Computational and Structural Biotechnology Journal*，不能因为其托管域名含 science 就称为 *Science Advances*。纳米颗粒毒性结果也不能直接当作所有块体无机晶体的毒性预测器。

以下七个子方向覆盖“可靠性、危害、暴露、可持续性和供应韧性”。它们有关联但不能混成一个无定义的安全分数。结构合法、低凸包距离和高目标性质都不足以证明使用安全；风险取决于材料形态、剂量、暴露途径、用途与生命周期。

### 7.2 七个可开题子方向

#### G1. 物理有效性与评估器误判

- **参考：** MatterGen与LeMat-GenBench [G1–G2]。
- **问题：** 现有有效性筛查在不同材料族上是否系统误拒合法结构、漏过异常结构？在等价晶胞表达下判定是否一致？
- **模型/数据：** MatterGen公开样本或小批生成；LeMat-GenBench已公布的基线数据；匹配的已知晶体作阳性对照，受控无效变体作阴性对照。
- **实验：** 核对电荷中性、原子间距、配位、密度、晶格和对称性；比较现有规则、按材料族校准的规则与学习型异常检测。报告合法性通过率、误拒率、异常召回、逐规则失败原因和 unknown 比例。
- **创新候选：** 给规则适用域和拒判机制；发现氧化态推断失败与物理不合法之间的区别。金属、合金或混合价体系不应被简单离子规则一刀切。
- **设备/优先级：** CPU即可对已有样本起步，GPU仅在重新生成/表示抽取时需要；P1，适合作为整体流程第一阶段。单独堆叠现成规则通常不足以形成方法贡献。

#### G2. 热力学、动力学和工作条件下的可靠性

- **参考：** [G1–G3]及原子势误差校准 [R8]。
- **问题：** 生成结构被预测稳定后，经一致参考计算或工作条件验证是否仍可靠？哪些不确定性信号能提前发现“假稳定”？
- **模型/数据：** MatterGen样本；固定版本的MACE/CHGNet评估；LeMat-GenBench对应参考凸包。
- **实验：** 对同一候选保存弛豫前后结构、能量与收敛状态，计算一致参考下的形成能和凸包距离。声子、弹性稳定条件、有限温度动力学作为分开的验证等级；比较单势评估、多势分歧与少量DFT复核，测假稳定率、分歧校准、验证成本和弛豫失败率。
- **创新候选：** 面向分布外生成结构的置信度校准和验证预算分配。弛豫后发生结构变化不一定是“崩掉”；先用结构匹配、收敛条件和相变判据定义失败。
- **设备/优先级：** GPU 16–24 GB小试验加CPU/DFT资源；P2。0 K热力学稳定、声子稳定、机械稳定、有限温度稳定和反应/燃爆危险是不同概念，不能相互代替。

#### G3. 可合成性与合成过程风险

- **参考：** 晶体生成综述 [G3]、SSbD/CHIASMA [G5–G6]。
- **问题：** 能否区分“有证据支持某条件下合成”与“缺少证据”？风险评估能否给出可追溯依据，而不是模型自信评分？
- **模型/数据：** 生成晶体配合公开合成文献与已核实实验结构；文献语料为待构建集合，不能把未找到论文的结构标为不可合成。若缺少可靠失败实验，优先研究正例—未标记学习或证据检索。
- **实验：** 固定材料族、实验条件与成功定义；比较相似已知结构检索、组成/结构分类器、证据约束模型。输出“有支持证据/条件受限/有失败证据/unknown”，按材料族或发表时间划分，测校准、覆盖率、错误乐观率和证据正确率。
- **创新候选：** 分开预测材料可获得性与工艺风险，定位前驱体、温压条件或副产物的证据缺口；专家对照复核一小批案例。
- **设备/优先级：** CPU检索+可选16–24 GB GPU；P2。危害判断需工艺和暴露数据，单一CIF不包含这些；不自动输出未经验证的危险合成操作方案。

#### G4. 毒性与暴露情景筛查

- **参考：** 纳米颗粒毒性预测 [G7]、CHIASMA [G6]；生物医药生成风险 [G9]只作安全动机参考。
- **问题：** 成分预警、结构/形态信息和暴露条件分别增加多少可信判断能力？模型何时应该拒绝给出“低风险”结论？
- **模型/数据：** 初期对生成无机晶体做带来源的成分/化学形态预警；若做监督毒性预测，必须取得有明确粒径、剂量、细胞/物种、暴露时间和终点的公开数据及许可。[G7]论文开放不自动证明其训练数据可下载。
- **实验：** 比较元素规则、传统RF/LightGBM与结构增强模型；按材料实体和数据来源隔离，报告高风险漏检率、PR-AUC、校准、适用域覆盖和unknown。毒性终点不同的标签不混训成同一“毒性值”。
- **创新候选：** 证据缺失下的选择性预测；把危害与暴露分开；跨纳米/块体或表面形态变化时的失效检测。
- **设备/优先级：** CPU可做基线，16–24 GB GPU用于结构表示；P2。含Pb/Hg/Cd/As可触发进一步核查，但元素名单不是完整毒性结论；含Cr不等于存在Cr(VI)。没有暴露资料时只能报告危害预警或信息不足。

#### G5. 环境与生命周期风险

- **参考：** SSbD [G5]和CHIASMA [G6]。
- **问题：** 只优化材料性能时，会遗漏哪些原料、生产、使用和报废负担？排名对工艺、能源和回收假设有多敏感？
- **模型/数据：** 生成材料组成+明确用途/工艺情景；可用公开且有许可的生命周期清单，缺失项显式标记。本轮不宣称已有覆盖所有生成晶体的开放LCA标签库。
- **实验：** 先固定功能单位、系统边界、地区/年份、电力情景和回收分配；比较单纯元素代理、分阶段清单估计与带区间评价。输出各环境影响维度、缺失比例和排序敏感性，不将供应集中度当作碳排放。
- **创新候选：** 稀疏清单下的不确定性传播；性能提升能否抵消生命周期负担；最有价值的补充数据选择。
- **设备/优先级：** CPU为主；P2，完整LCA可升为P3。没有制造路线时只能给情景或代理估计，不能从CIF直接声称测得碳足迹；工艺数据工作量通常比GPU需求更大。

#### G6. 元素供应风险与韧性

- **参考：** LeMat-GenBench中的HHI [G2]；供应与生命周期分维度评价参照 [G5]。
- **问题：** 生成器是否偏向依赖高度集中来源的元素？结论是否随年份和生产/储量口径改变？
- **模型/数据：** 固定MatterGen生成集；LeMat-GenBench内HHI数据和计算定义，补充时采用有年份的官方矿产统计。
- **实验：** 复现生产/储量集中度，注明国家份额归一化和指数尺度；比较元素最大值、成分加权值等聚合，并说明质量分数或原子分数的选择。报告性能—供应风险Pareto前沿和不同年份敏感性。
- **创新候选：** 结合替代性与数据不确定性，研究约束如何改变材料族分布和多样性；仅新增一个HHI列不是新贡献。
- **设备/优先级：** CPU即可；P1可作为入门子任务，与G1组成初步评价。HHI不是稀缺程度、价格、毒性或地缘风险的完整代理；缺失数据不记为零风险。

#### G7. 多目标安全约束生成

- **参考：** MatterGen [G1]、材料基础模型综述 [G4]、通用LLM对齐 [G8]。
- **问题：** 相同生成/验证预算下，约束引导能否提高满足性能和风险约束的候选产出，而不牺牲全部多样性？
- **模型/数据：** 先使用固定MatterGen检查点和已验证的G1/G2/G6评价器；毒性、可合成性和LCA证据不足时保留unknown，不把不可靠预测硬加入奖励。
- **实验：** 比较无约束生成、生成后过滤、候选重排和条件/引导生成。固定随机种子、尝试次数和验证资源，报告全部生成样本上的约束满足率、每预算候选产出、性能、唯一性、新颖性与多样性，以及独立验证下的失败率。
- **创新候选：** 不确定性约束、选择性生成与验证成本分配；防止优化器利用评价器盲点。训练奖励与最终验证模型/数据应隔离。
- **设备/优先级：** 先已有样本重排，CPU或单张24 GB GPU；微调/引导另按模型实测，可能需要48–80 GB或多卡。P2/P3，放在评价器经过验证之后。无需先上RLHF，通用LLM对齐只能作为思想对应。

### 7.3 第一个学生项目：用评估证据连接安全与材料科学

建议题名：**Evidence-aware Safety Screening of AI-generated Inorganic Materials**（暂定选题，不是已有论文）。

最小闭环：

1. 在一个用途与材料族内，先选约500–2,000个公开生成结构，记录生成器和样本来源；另配匹配的已知材料。可访问性/许可未确认前不承诺具体数量。
2. 复现G1有效性与G6供应指标，加入G2固定版本势函数弛豫；逐项输出判据、证据来源、适用域、置信度或unknown。
3. 对“高性能但多指标冲突/证据不足”的候选分层抽样复核。比较仅稳定性筛选、简单规则交集、带不确定性的选择性筛选。
4. 主要指标：错误放行率、正常候选误拒率、覆盖率—风险曲线、unknown比例、每预算有效候选数和Pareto前沿。只有在有独立参考标签的子集上才计算真假安全判定。
5. 约20个小结构做DFT可行性试验；毒性与工艺环节先做专家证据核查，没有真值不编造安全标签。以可重复的评价失效机制为论文核心。
6. 若筛查有效，再开展G7“生成后过滤 vs 生成中约束”。不一开始生成十万结构，也不把全部unknown过滤掉后得到的“零风险”当作成功。

**输出应称为“满足已检验条件的待验证候选”，不是“安全材料”。** 建议每项结果采用“通过当前检查 / 风险提示 / 证据不足 / 不适用”，不要强行压缩为一个安全/不安全二分类。具体用途、剂量、制造路线、服役条件和报废途径改变时应重新评估。

可沿用第10节12周安排，但将第1–2周改为限定用途与评估终点，第3–4周复现G1/G6，第5–6周分析G2和unknown，第7–10周开展证据筛选、专家/DFT子集核查与对照，第11–12周整理评价协议和失败案例。

## 9. 所有方向共用的实验协议

1. **先写资产和权限。** 谁拥有私有数据/模型？攻击者能改什么、知道什么、查询多少？普通噪声、分布外失效与恶意攻击分别定义。
2. **固定版本与划分。** 记录模型 commit/checkpoint hash、数据源和快照、许可、过滤逻辑、材料/轨迹组 ID。分别说明预训练重叠、微调重叠和测试泄漏。
3. **实验逐步扩展。** 先一个模型跑通，再做第二个不同架构；预训练基础模型、从头训练模型和简单特征基线承担不同对照角色。
4. **目标、约束与指标预先声明。** 回归攻击的成功可定义为定向误差越过预设阈值，阈值由干净验证集和材料任务确定；不能看测试结果后挑阈值。
5. **成对报告效用和安全。** 整体/目标族误差、正常效用、攻击效果、检测误报与成本同时给出。Top-K 重合下降不一定是坏事，需要真实标签判定候选质量。
6. **随机性与统计。** 建议至少 3 个随机种子，报告均值、离散程度和失败次数；样本相关时按材料或轨迹簇 bootstrap。低 FPR 不得超过样本能支持的精度。
7. **检测与攻击隔离。** 检测器不接触最终测试攻击标签；增加未见材料族/攻击方式。防御必须接受自适应攻击，并报告被拒绝的正常任务。
8. **物理参考分层。** 已有标签、代理模型、DFT和实体验证分别标记。对新结构缺真值的试验只报告代理异常；不补造计算值，也不把未做实验写成材料发现。
9. **发布内容可追溯。** 原始数据不改写；污染以补丁/索引表示，标记为实验变体。只在自己或明确授权的环境运行，不向公共数据源提交污染数据。

**一次运行应保存的最小记录：** 方向 ID、模型/数据版本、分组划分、攻击权限、预算分母、污染索引或扰动约束、干净对照、种子、检测阈值来源、参考标签来源、指标及样本数、峰值显存、实际耗时和失败日志。

## 10. 设备规划与 12 周实施安排

预算是方案级估计，不能理解为指定模型的已验证最低配置。

| 档位 | 建议配置 | 能先做什么 |
|---|---|---|
| A | CPU，32 GB RAM，约 100 GB 可用空间 | 文献、静态审计、索引、简单 ML、小规模供应链实验 |
| B | 单张 16–24 GB GPU，64 GB RAM，约 0.5–1 TB空间 | 小结构微调、投毒、模型窃取、轻量成员推断、小 LLM 推理 |
| C | 48–80 GB GPU或多卡，按数据量增加内存/磁盘 | 更大多模态模型、批量影子模型和大结构；不是第一篇的必要条件 |
| D | 另配多核 CPU/DFT集群与材料合作者 | 新结构标签、弛豫与物理验证；不能仅按 GPU 显存估算成本 |

不要从全量预训练开始，也不要一开始下载全部大型材料库。先用 100 个样本测吞吐、显存、存储，再规划 1k–10k 的微调子集；这只是试验规模建议，论文规模由统计效力与问题覆盖决定。

| 周次 | 任务 | 必须交付 / 决策 |
|---|---|---|
| 1–2 | 阅读对应安全参考和材料模型论文，确认数据许可与硬件 | 一页威胁模型；可核对的数据样本与分组方案 |
| 3–4 | 完成干净基线和简单攻击/噪声对照 | 可复现配置、指标和误差分析；基础模型任务头须正常学习 |
| 5–6 | 预算曲线、分族评测与失败案例 | 证明效果不是数据泄漏、单位错误或物性真实变化 |
| 7–8 | 一个有明确机制的检测/防御方法 | 与简单基线对比；报告安全—效用权衡 |
| 9–10 | 第二模型、未见材料族和自适应攻击 | 迁移、消融、统计区间和实际算力记录 |
| 11–12 | 核验创新边界，整理复现材料与初稿 | 明确支持/不支持的主张、限制与负结果 |

**第 4 周止损点：** 若标签/划分不可控，先解决数据问题；若新增结构无法取真值，转向 D1 或 S2；若攻击只和随机噪声相当，不追加复杂模块掩盖，应重新检查威胁模型并记录负结果。12 周是工作安排，不是论文录用或有效攻击保证。
