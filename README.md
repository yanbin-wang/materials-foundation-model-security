# Materials Foundation Model Security

**面向安全专业学生的研究路线图**

> 以生物与医疗领域已验证的大模型安全工作为参照，系统评估**开源材料基础模型**（机器学习原子间势 MLIP + 晶体生成模型）的数据投毒与后门风险，并建设可复现基准。

更新：2026-10-15

---

## 一、背景与意义

近年来，机器学习原子间势（MLIP）和晶体生成模型（如 MACE、CHGNet、MatterGen 等）已成为材料科学研究的重要基础设施。它们被广泛用于加速新材料的性质预测、稳定性筛选和逆向设计，显著降低了传统高通量计算的成本。这些模型通常在大规模公开数据集上预训练，并以开源方式发布权重，极大促进了社区的使用与二次开发。

然而，正是这种“大规模公开数据 + 开源权重”的范式，带来了此前被严重忽视的安全风险。已有研究表明，通用大语言模型、医疗大模型、基因组基础模型和蛋白基础模型均对数据投毒和后门攻击高度敏感：攻击者只需污染极小比例的训练数据，就能在特定触发条件下操纵模型行为，同时保持在常规测试集上的性能几乎不变。相比之下，**材料基础模型的系统性投毒与后门评估仍较为缺乏**。

材料基础模型一旦被植入后门或遭受针对性投毒，攻击者可以在常规测试指标几乎不受影响的情况下，系统性地操纵特定材料体系的能量与力预测。这会导致形成能排序被扭曲、稳定性筛选结果被翻转，使本应被排除的不稳定或高风险结构被优先推荐进入下游计算或实验验证环节。由于这些模型已被广泛用于电池、催化剂、合金、半导体等关键材料的高通量筛选，隐蔽的定向操纵可能沿着“计算筛选 → 实验验证 → 工业应用”的链条放大。

从更宏观的层面看，关键材料的发现与优化直接关系到能源安全、先进制造、国防工业和绿色低碳转型。错误的筛选结果可能导致大量实验资源浪费、研发周期拉长，甚至在储能、催化等战略领域引入潜在安全隐患。随着材料人工智能在国家和产业层面的加速部署，模型结果的可信度已不再只是学术问题，而可能影响资源配置效率、产业竞争力和关键技术的自主可控。

**本研究的意义**：

1. **填补空白**：将已在生物与医疗领域验证的威胁模型迁移到材料科学，首次系统揭示材料基础模型作为科学基础设施的安全风险。
2. **建立标准**：提供统一的威胁模型、攻击方法和评估协议，为后续防御研究和模型发布提供可参考的安全评估基准。
3. **实际价值**：帮助模型开发者和使用者识别潜在风险，推动材料人工智能在数据溯源、完整性验证和对抗鲁棒性方面的规范建设，服务于更可信的材料发现流程，支撑关键材料领域的可靠决策。

## 二、研究定位

本仓库的目标是：

- 把生物/基因组/医疗领域已经验证过的投毒与后门范式，迁移到材料模型上；
- 系统评估这些模型对数据投毒和结构后门的脆弱性；
- 建立可复现的攻击基准与评估协议。

**当前聚焦的核心问题**：

1. **数据投毒**：在微调数据中注入定向污染，观察对能量/力预测和下游筛选排序的影响。
2. **条件后门**：在微调阶段植入结构触发器，测试是否只在触发时生效、能否在额外微调后存活。

核心思路是**照猫画虎**：把其他科学领域已经验证过的投毒与后门方法，迁移到材料基础模型上。这些科学领域的工作本身也大量参考了通用模型（LLM、视觉模型）上的投毒与后门方法。

## 三、必须精读的参照工作

### 科学领域参照（优先）

| 论文 | 核心贡献 | 我们主要借鉴什么 |
|------|----------|------------------|
| [Poisoning the Genome](https://arxiv.org/abs/2603.27465) (2026) | 基因组基础模型的系统投毒与后门（研究了 2 个架构，一篇文章里完成预训练投毒 + 微调后门 + 下游评估） | 完整流程与低比例投毒 + 高隐蔽性设计；威胁模型与评估指标可直接迁移 |
| [SafeProtein](https://arxiv.org/abs/2509.03487) (2025) | 蛋白基础模型红队与基准 | 基准构建方式与评估协议 |
| Medical LLM poisoning (Nature Medicine, 2025) | 极低比例投毒（0.001%）即可生效且高度隐蔽 | 低比例污染 + 常规 benchmark 无明显下降的隐蔽性设计 |

**为什么优先模仿 Poisoning the Genome？**  
这是目前科学基础模型投毒最完整的模板，威胁模型划分、攻击阶段设计、评估指标都可以直接迁移。

### 通用模型参照（方法源头）

科学领域的工作大多建立在通用模型投毒与后门方法之上，以下可作为补充阅读：

| 论文 | 核心贡献 | 说明 |
|------|----------|------|
| [BadNets](https://arxiv.org/abs/1708.06733) (2017) | 早期后门攻击经典工作 | 触发器 + 条件行为的基本范式 |
| [Clean-Label Backdoor Attacks](https://openreview.net/forum?id=HJg6e2CcK7) (ICLR 2019) | 干净标签后门 | 更隐蔽的投毒方式 |
| Poisoning Attacks on LLMs（多篇） | 大语言模型数据投毒 | 低比例污染与隐蔽性设计的直接来源 |
| [Graph Backdoor](https://www.usenix.org/conference/usenixsecurity21/presentation/xi) (USENIX Security 2021) | 图模型后门 | 与晶体图结构相关，可作结构触发器参考 |

## 四、推荐研究的模型

优先选择 2–3 个开源模型：

| 模型 | 类型 | 推荐理由 |
|------|------|----------|
| **MACE** (MACE-MP-0 / MACE-MPA-0) | MLIP | 当前最主流的通用材料基础势 |
| **CHGNet** | MLIP | 使用广泛，开源成熟，容易上手 |
| **MatterGen** | 晶体生成模型 | 最有代表性的材料生成模型（可后期做） |

## 五、核心实验设计（照猫画虎）

对照 *Poisoning the Genome* 的实验结构，迁移如下：

| 参照实验 | 材料对应实验 |
|----------|--------------|
| 预训练 / 微调阶段投毒 | 在 MPtrj 或可控子集中注入不同比例的污染结构，测试对能量、力、形成能排序的影响 |
| 条件后门 | 设计简单结构触发器，在微调数据中植入，测试触发时生效、干净样本不受影响、额外微调后是否存活 |
| 下游任务影响 | 观察对材料筛选排序、稳定性判断的操纵效果 |
| 隐蔽性评估 | 干净测试集性能几乎不变，触发/目标子集性能明显下降 |

**关键注意点**：

- 材料数据是周期晶体结构，触发器必须保持物理合理性（最小原子间距、电荷中性等）。
- “攻击成功”的定义需要提前约定阈值（例如能量偏差超过一定 meV/atom）。
- 先做标签污染（数据投毒），结构后门作为第二步。
- **材料特有的重点创新点**：如何设计有效的结构触发器（几何扰动、局部结构变化等）。

## 六、后续可能的扩展方向

在完成数据投毒与后门基准之后，可考虑以下方向：

- **科学生成模型的红队评估**：针对 MatterGen 等晶体生成模型，评估在特定提示或约束下生成不稳定或潜在危险结构的能力（参考 SafeProtein 的思路）。
- **水印与溯源**：为晶体生成模型设计可检测的水印，用于模型知识产权保护与滥用追踪。可参考蛋白领域的工作：
  - [FoldMark](https://arxiv.org/abs/2410.20354)：蛋白生成模型的水印嵌入与检测
  - [MARCO](https://arxiv.org/abs/2610.08316)：具有“放射性”转移特性的蛋白生成模型水印
  - SynthID Bio（Google DeepMind, Nature 2026）：功能保持的 AI 设计蛋白水印
- **科学 Agent 安全**：针对材料/化学工作流 Agent，研究工具调用安全、错误累积与双重用途监控。

这些方向目前不作为主线，是否推进取决于第一阶段工作的进展与可用资源。
