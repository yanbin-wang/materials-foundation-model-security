# Materials Foundation Model Security

**面向安全专业学生的研究路线图**

> 以生物与医疗领域已验证的大模型安全工作为参照，系统评估**开源材料基础模型**（机器学习原子间势 MLIP + 晶体生成模型）的数据投毒与后门风险，并建设可复现基准。

更新：2026-10-15

---

## 一、研究定位

材料基础模型（如 MACE、CHGNet、MatterGen）正成为新材料发现的核心计算工具。它们大量依赖公开数据与开源权重，但针对其的安全研究几乎空白。

本仓库的目标是：

- 把生物/基因组/医疗领域已经验证过的投毒与后门范式，迁移到材料模型上；
- 系统评估这些模型对数据投毒和结构后门的脆弱性；
- 建立可复现的攻击基准与评估协议。

**第一优先级只聚焦以下两个问题**（其他方向作为后续扩展）：

1. **数据投毒**：在微调数据中注入定向污染，观察对能量/力预测和下游筛选排序的影响。
2. **条件后门**：在微调阶段植入结构触发器，测试是否只在触发时生效、能否在额外微调后存活。

## 二、必须精读的参照工作

| 论文 | 核心贡献 | 我们主要借鉴什么 |
|------|----------|------------------|
| [Poisoning the Genome](https://arxiv.org/abs/2603.27465) (2026) | 基因组基础模型的系统投毒与后门 | 完整流程：预训练投毒 + 微调后门 + 下游评估；低比例投毒 + 高隐蔽性 |
| [SafeProtein](https://arxiv.org/abs/2509.03487) (2025) | 蛋白基础模型红队与基准 | 基准构建方式与评估协议 |
| Medical LLM poisoning (Nature Medicine, 2025) | 极低比例投毒即可生效 | 低比例污染 + 常规 benchmark 无明显下降的隐蔽性设计 |

## 三、推荐研究的模型

优先选择 2–3 个开源模型：

| 模型 | 类型 | 推荐理由 |
|------|------|----------|
| **MACE** (MACE-MP-0 / MACE-MPA-0) | MLIP | 当前最主流的通用材料基础势 |
| **CHGNet** | MLIP | 使用广泛，开源成熟，容易上手 |
| **MatterGen** | 晶体生成模型 | 最有代表性的材料生成模型（可后期做） |

## 四、第一优先级实验设计（照猫画虎）

对照 *Poisoning the Genome* 的实验结构，迁移如下：

| 参照实验 | 材料对应实验 |
|----------|--------------|
| 预训练 / 微调阶段投毒 | 在 MPtrj 或可控子集中注入不同比例的污染结构，测试对能量、力、形成能排序的影响 |
| 条件后门 | 设计简单结构触发器，在微调数据中植入，测试触发时生效、干净样本不受影响、额外微调后是否存活 |
| 下游任务影响 | 观察对材料筛选排序、稳定性判断的操纵效果 |
| 隐蔽性评估 | 干净测试集性能几乎不变，触发/目标子集性能明显下降 |

**关键注意点**：

- 材料数据是周期晶体结构，触发器必须保持物理合理性（最小原子间距、电荷中性等）。
- “攻击成功”的定义需要提前约定阈值（例如能量偏差超过一定 meV/atom）。
- 先做标签污染（数据投毒），结构后门作为第二步。

## 五、学生执行步骤

### 阶段 0（2–3 周）
- 精读上述 3 篇参照论文，整理可迁移组件清单。
- 跑通 MACE 和 CHGNet 的推理与微调。

### 阶段 1（3–4 周）
- 定义威胁模型与攻击目标。
- 设计并测试简单的结构触发器。

### 阶段 2（6–8 周）
- 完成数据投毒实验（不同污染比例）。
- 完成条件后门实验（存活率测试）。
- 统一评估指标（ASR、干净性能下降、隐蔽性）。

### 阶段 3
- 整理开源基准仓库。
- 撰写论文。

---

## 六、暂不作为第一优先级的方向

以下方向可以保留，但不建议作为学生第一阶段的主线：

- 复杂的结构后门（需要大量 DFT 真值）
- 权重篡改
- 物理约束下的对抗攻击
- 结构重构 / 成员推断
- 生成材料的双重用途评估（评价器本身还不成熟）

这些方向需要更强的材料背景或计算资源，适合作为后续扩展。
